# ToDo List App (React + Vite + SCSS Modules)

Менеджер задач с поддержкой ежедневных заданий, постоянных заметок и таймера.
Данные хранятся локально в браузере (localStorage), не требуют сервера.


# Demo https://omnesmorimur.github.io/Todo/

-------------------------------------------------------------------------------------------

## Возможности

**Основной список задач** — добавление, удаление, выполнение, поиск
**Ежедневные задачи** — автоматический сброс отметок каждый день в 7:00 МСК (по умолчанию, но можно настроить время)
**Постоянные заметки** — идеи, ссылки, списки книг/фильмов 
**Таймер** — с звуковым оповещением и уведомлениями
**Комментарии к задачам** — подробные заметки к каждой задаче
**Адаптивный дизайн** — работает на телефонах и компьютерах (без PWA)
